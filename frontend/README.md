# 班级德育学分座次选择系统 - 前端

本项目基于 React 18 + Ant Design 5 + Vite 构建，采用 Zustand 进行全局状态管理，使用 React Router v6 组织路由。

## 环境要求
- Node.js 18+
- npm 或 pnpm

## 快速启动

1. **安装依赖**
```bash
npm install
```

2. **配置环境变量**
在 `frontend` 目录下新建 `.env` 文件，配置后端接口地址（如果后端运行在本地 8000 端口可省略此步）：
```env
VITE_API_BASE_URL=http://localhost:8000
```

3. **启动开发服务器**
```bash
npm run dev
```

4. **构建生产版本**
```bash
npm run build
```

## 功能模块说明

### 管理员端 (`/admin`)
- **数据仪表盘**：查看全局统计数据。
- **选座控制台**：核心流程控制，包括准备排名、开启选座、推进队列、跳过学生等。
- **座位图管理**：新建教室布局，可视化查看座位。
- **学生管理**：批量导入德育学分、增删学生账号。
- **换座审核**：审核学生提交的换座申请。
- **系统设置**：配置参数、开关功能。

### 学生端 (`/student`)
- **选座大厅**：可视化选座，每5秒轮询最新状态，轮到自己时可点击可选座位。
- **我的座位**：查看当前分配和历史选座记录。
- **换座申请**：发起与同学的座位交换申请。
- **消息中心**：查看系统通知（占位，待完善）。

## 技术栈细节
- **网络请求**：使用 `axios`，在 `src/services/api.ts` 中封装了请求拦截器，自动携带 JWT Token，以及统一的响应拦截处理 401 错误与提示信息。
- **状态管理**：使用 `zustand` 结合 `persist` 中间件实现持久化的登录状态存储 (`src/stores/useAuthStore.ts`)。
- **路由保护**：`src/App.tsx` 中实现了 `ProtectedRoute`，根据角色控制路由权限拦截。
